# 🚀 TorrServer + Caddy Manager (Docker)

Интерактивный Bash-скрипт для автоматического развертывания **TorrServer** в связке с обратным прокси **Caddy** (через Docker). Скрипт берет на себя всю рутину по настройке сети, выпуску SSL-сертификатов и управлению пользователями.

## 🌟 Главные фишки
* **Полная автоматизация:** Установка Docker, настройка Firewall (UFW) и генерация конфигов в пару кликов.
* **Безопасность (HTTPS):** Выпуск бесплатных SSL-сертификатов Let's Encrypt через `acme.sh`.
* **Умное автопродление без конфликтов:** Продление сертификатов работает через `cron` и внутренний механизм Caddy (`reloadcmd`). Это **не конфликтует с панелью 3x-ui**, так как пути сертификатов и рабочие порты строго разделены!
* **Изоляция:** Сервисы работают в Docker-контейнерах, не загрязняя основную систему.
* **Многопользовательский режим:** Создавайте отдельные логины и пароли для друзей с защитой учетной записи главного администратора от случайного удаления.
* **Транзакционные бэкапы:** При смене домена, порта или версии скрипт делает резервные копии и умеет откатываться в исходное состояние при малейших ошибках.

## ⚠️ Важные требования перед установкой
1. **OC**: Скрипт разработан для дистрибутивов на базе Debian/Ubuntu (использует `apt`, `ufw`, `systemd`). 
   Протестирован на **Ubuntu 24.04**. Теоретически должен работать без изменений на Ubuntu 22.04/20.04 и Debian 11/12, 
   но эти версии полноценно не проверялись.
2. **Доменное имя:** У вас должен быть домен (или поддомен), который уже направлен (через A-запись) на IP-адрес вашего сервера.
3. **Свободные порты:** Для успешного выпуска сертификата **порт 80 должен быть свободен**. Убедитесь, что на сервере не висят старые веб-серверы (Apache/Nginx), занимающие этот порт.

## 🛠 Установка (Команда в одну строку)
Подключитесь к вашему серверу по SSH под пользователем `root` (или через `sudo -i`) и выполните эту команду:

```bash
wget -O manager.sh https://raw.githubusercontent.com/Feavenchik/torrserver-docker-manager/main/manager.sh && chmod +x manager.sh && ./manager.sh
```

## 📋 Возможности меню
После первоначальной установки скрипт сохраняется на вашем сервере. Вы можете в любой момент снова запустить его командой **./manager.sh** чтобы получить доступ к функциям:
1. Установить TorrServer (Docker)
2. Обновить / Понизить версию TorrServer
3. Управление пользователями (Добавить / Удалить / Сменить пароль)
4. Изменить рабочий порт
5. Изменить доменное имя
6. Полное удаление сервисов с сервера
